multi-git

Configure multiple Git identities (personal and work) on one machine — with a cross-platform CLI.

Detected system: detecting…

Install with one command:

curl -fsSL https://guionardo.github.io/multi-git/install.sh | bash

What it does

  • Detects SSH keys, gh/az CLIs and existing Git config.
  • Generates ~/.gitconfig with includeIf rules for ~/personal and ~/work.
  • Creates per-identity overrides and SSH config with IdentitiesOnly yes.
  • Builds ~/.ssh/allowed_signers for SSH commit signing.
  • Backs up existing files (.bak.<timestamp>) and asks before overwriting.
  • Validates the result with multi-git verify.

Commands

multi-git detect    # show detected setup
multi-git status    # show current config status
multi-git wizard    # guided interactive setup (TUI)
multi-git apply     # generate/update configuration
multi-git verify    # validate configuration
All install commands

Linux / macOS / WSL (bash):

curl -fsSL https://guionardo.github.io/multi-git/install.sh | bash

Windows (PowerShell):

irm https://guionardo.github.io/multi-git/install.ps1 | iex

With arguments (example):

curl -fsSL https://guionardo.github.io/multi-git/install.sh | bash -s -- wizard --dry-run
# PowerShell:
$env:MULTI_GIT_ARGS="wizard --dry-run"; irm https://guionardo.github.io/multi-git/install.ps1 | iex

From source:

git clone https://github.com/guionardo/multi-git.git
cd multi-git/cli
go build -o multi-git .
./multi-git wizard

Manual install (no script)

Download a binary from the releases page, or build from source:

git clone https://github.com/guionardo/multi-git.git
cd multi-git/cli
go build -o multi-git .
